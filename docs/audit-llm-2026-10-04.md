# GLM / harness audit — 4 October 2026

## Scope and evidence

- Live provider: configured `z-ai/glm-5.3-flash`, through the actual Snaap Responses API harness. Ten logical chat requests, at most two concurrent; 14 completed provider rounds reported across nine successful requests. A tenth request timed out before a response was received.
- Synthetic owners and workspaces in a separate UTF-8 PostgreSQL database. No real account history, images, keys, real orders, enabled setups or external notifications used. Public instrument lookup occurred for draft validation.
- Existing request cap retained at USD 0.03. Observed reported usage: **238,187 input tokens / 3,667 output tokens / USD 0.06688075**. Timeout usage was unavailable, so this is recorded usage, not an invoice guarantee.
- Nine responses returned HTTP 200; one returned HTTP 502 after 45 seconds. Successful latency 7.681–51.165 seconds; median 30.724 seconds. Quota was refunded for the failed request.
- Raw synthetic responses, usage and traces: `.local/audit/persona-llm-2026-10-04.json`. Reusable bounded driver: `scripts/audit-persona-llm-2026-10-04.ts`. The recorded live run preceded the privacy fix below; reruns now explicitly set the personal-data toggle for history personas.
- This is **not ten elapsed days of live observation**. The ten-day scenario matrix below is a compressed test plan; ten paid initial interactions were actually run. Idle-day workflows belong to deterministic system/monitor tests.

## Confirmed privacy issue fixed during audit

Before fix, a turn with `useMyData:false` and omitted `selection` sent all default owner import context to the mock provider. Regression assertion reproduced the private sentinel in `instructions`.

`src/ai/harness.ts` now:

1. Requires `useMyData:true` before any import history is attached; false overrides stale explicit import IDs and defaults unselected rules to none. Explicit setup IDs remain available for setup analysis.
2. Requires the toggle before library images can be used. Images attached to the current conversation remain allowed when personal data is off.
3. Omits older messages referencing private import/library sources when the toggle is switched off, preventing carry-over of a previous private-data answer.

Mock provider regression passes omitted selection, stale import selection, enabled history, enabled→disabled history, and disabled library images. Existing contract checks still pass: incomplete output/refund, concurrent owner lock, deleted evidence, false action repair, invalid crops. TypeScript check passed.

## Remaining product / harness gaps

- Baseline policy plus complete indicator catalog and strategy schema consumed about **15,800 input tokens even for a joke or elementary explanation**. History specialist interactions used about 37,800 input tokens; repaired draft used 48,468. Consider intent-specific catalog/schema loading and less repeated policy before raising quotas or swapping models.
- Model can produce invalid tool fields but backend rejects and model repairs; successful schema recovery currently adds latency. Keep validation strict; improve model examples/schema clarity rather than accepting invalid fields.
- Professional tone is improved but not guaranteed: fabricated image presence, execution-to-intention inference, and technical receipt prose occurred in real answers. These need evaluation cases and targeted policy/metadata improvements, not a claim that prompts enforce truth.
- No order/position live tool, no web news tool, no matched-position journal statistics. Imported fills alone cannot classify holding-duration style or calculate whole-account win rate. Harness cannot make unavailable capabilities complete by wording changes.
- A time-out may incur provider-side cost not reported to the client. Refunded quota is not proof of zero provider billing.
