## การตรวจหลังแก้

- TypeScript และ syntax ของ frontend ผ่าน
- Unit tests 23/23 รวม MACD numerical regression
- Integration tests ผ่าน ownership, CSRF, version conflicts, quota, persistence, monitor dedup และ billing lifecycle แบบจำลอง
- แก้ flaky assertion ใน integration ที่ใช้เวลาคนละ clock ระหว่าง DB กับ JavaScript โดยเผื่อ 1 วินาที (ยังตรวจว่าเหลือประมาณ 30 วัน ไม่ใช่ 60 วัน)
- `scripts/audit-system.ts` เพิ่ม assertions สำหรับ invalid activation, historical context, latest/older messages และ invalid files
- Persona suite: 420 virtual user-days, 1,541 API calls, 855 monitor calls, **207/207 checks ผ่าน**; failure ทำให้สคริปต์ exit ด้วย error
- เกณฑ์ quota เปลี่ยนให้ตรงพฤติกรรมผลิตภัณฑ์: ตรวจว่าบล็อกอย่างชัดเจนและกลับมาทำงานหลังผู้ใช้จัดการสิทธิ์ ไม่ได้ปล่อยให้ใช้เกินแพ็กเกจ
- ตรวจ browser จริง: ไม่มี console warnings/errors ในเส้นทางกราฟที่ตรวจ

## ขอบเขตที่ยังไม่ควรเรียกว่าเสร็จครบผลิตภัณฑ์

- AI, Google, Stripe และการส่ง Telegram/LINE/Webhook จริงยังต้องใช้การตั้งค่าผู้ให้บริการและทดสอบ E2E
- การ sync ประวัติผ่าน API ยังรองรับ Binance/Bybit Spot แบบ partial batch ที่เปิดเผยขอบเขต ส่วนอีก 3 กระดานยังเป็น CSV ตามหน้า UI; ไม่ได้อ้างว่าเป็น full account history
- การเก็บร่างแยกจากเซตอัปที่เปิดอยู่, การเลือกชนิดเหตุการณ์ที่จะส่ง และหน้าคำอธิบาย “ทำไมยังไม่แจ้ง” เป็นฟีเจอร์ต่อยอดจากรายงาน ไม่ได้รวมอยู่ในการแก้บั๊กครั้งนี้ การบันทึกแก้ไขเซตอัปยังพักเพื่อรอยืนยันตามพฤติกรรมเดิม
- ไม่ได้รัน soak 48 ชั่วโมง หรือรับรองโหลด AI/กราฟ 100 คนจากชุดทดสอบอ่านข้อมูล
- ข้อมูลตลาดสังเคราะห์ไม่ใช่ผลตอบแทนหรือหลักฐานความพอใจของผู้ใช้จริง

อ้างอิงการแบ่งหน้าข้อมูลตลาด: [CCXT Manual](https://github.com/ccxt/ccxt/wiki/Manual) — since/limit และความสามารถขึ้นกับแต่ละกระดาน จึงยังต้องแสดงข้อมูลไม่พอเมื่อกระดานให้มาไม่ครบ
