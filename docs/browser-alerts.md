# การแจ้งเตือนในเบราว์เซอร์

- การแจ้งเตือน → ช่องทาง มีปุ่มเปิดแจ้งเตือน Chrome เปิด/ปิดเสียง และลองเสียง
- ขอ `Notification.requestPermission()` เฉพาะหลังผู้ใช้คลิก ไม่รบกวนตอนเปิดเว็บ
- ถ้าบล็อกไว้ ผู้ใช้เปลี่ยนสิทธิ์ที่ไอคอนข้าง URL; เว็บขอซ้ำเองไม่ได้
- เสียง Web Audio ต้องเริ่มจากการคลิก หลังรีเฟรชจะปลดล็อกเมื่อผู้ใช้แตะเว็บหากเคยเปิดเสียง
- ตั้งค่าบนอุปกรณ์นี้แยกตาม user ID; ไม่เก็บคีย์หรือข้อมูลบัญชีใน preference
- อ่านสัญญาณทุกเวิร์กสเปซของบัญชีปัจจุบันทุก 15 วินาที ใช้ cursor `after` จาก API ที่ตรวจ owner เสมอ
- การเปิดเว็บเริ่มจากสัญญาณล่าสุดเป็น baseline ไม่แจ้งประวัติเก่า; หลังเชื่อมต่อกลับใช้ cursor เดิมอ่านต่อ
- สัญญาณหลายรายการรวมเป็นการแจ้งเตือนเดียวต่อรอบ และเสียงสั้นหนึ่งชุด
- เปิดแท็บทิ้งไว้จึงรับการแจ้งเตือนเบราว์เซอร์ได้; Chrome อาจหน่วงแท็บที่พักไว้ ระบบนี้ยังไม่มี Web Push สำหรับตอนปิดเว็บ
- Worker บนเซิร์ฟเวอร์ยังตรวจสัญญาณและส่งช่องทางภายนอกแม้ปิดเว็บ

อ้างอิง: [Notifications API](https://developer.mozilla.org/en-US/docs/Web/API/Notifications_API), [Web Audio best practices](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices)
